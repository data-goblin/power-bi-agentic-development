# v26.31.4

## Omarchy themes for Power BI

- `useful-stuff/themes/`: 22 Power BI report themes generated from the built-in Omarchy desktop themes, from Vantablack to White. Each sets a monospace font stack (`'JetBrainsMono Nerd Font', 'JetBrains Mono', Consolas, monospace`), maps the Omarchy palette onto pages, visuals, tables, matrices, button slicers and tooltips, and picks dim text by contrast so labels stay readable on the light themes
- Tables and matrices keep tooltips on but fully transparent, so SVG image cells no longer show their `data:image/svg+xml` URI on hover (with tooltips switched off, Power BI falls back to showing the raw URL)
- The README lists every theme dark to light with its background and series colour, and how to apply one in Power BI Desktop or with the pbir CLI

## svg-visuals

- `custom-visuals/svg-visuals`: image visual host for SVG-only content, IBCS delta and pin templates, and a template matrix with verified card and button slicer wiring; template cells documented at 110 x 24 and 140 x 24

## te-cli

- `tabular-editor/te-cli`: re-synced with upstream TabularEditor/CLI; no upstream changes since the last sync. Verified against `te` 0.7.1.2 (CDN build 2026-09-22)
