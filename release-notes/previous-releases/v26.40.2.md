# v26.40.2

> [!WARNING]
> Mods only work in Claude Code 2.1.287 or newer. In other tools, such as Copilot CLI, the panes do not appear.

- All panes: the "Claude is working in ..." text and the row shimmer now start and stop at the same moment, in the same colour
- `fabric-cli` and `databricks-cli`: when the CLI is missing, you are not signed in or the service can't be reached, the pane shows the steps to fix it, with commands you can copy; the Fabric pane also shows fab's real error message instead of `error: {`
- `reports`: every visual type has its own icon (FabricSymbols NF now has 907 glyphs), custom visuals show their name and a puzzle piece, and a theme shows a paint palette
