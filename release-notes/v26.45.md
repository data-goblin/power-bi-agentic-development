# v26.45

- Tabular Editor: `te-cli` matches te CLI 0.8.0, with `schemacheck`, the linguistic metadata deploy flag and the new expiry date. The download URL uses the new pattern (#46). New `dax-test-patterns.md` reference with DAX test patterns and measure contracts, checked against a deployed model.
- Semantic models: `dax` has a new `udf-authoring.md` reference for writing DAX user-defined functions.
- Dashboards: `querying-fabric` has a new `lint_dax.py` script. It flags `FILTER` over whole tables, row iterators, `CURRENTGROUP`, date literals and repeated filters before a query runs.
- Panes: the Fabric, Fabric app, Report and Databricks panes get the fixes from filetree. They open at once from their slash commands, show button presses before slow work, find Nerd Fonts correctly, copy with right-click and stop showing aborted runs as missing or failed. The Fabric app pane starts again after a forked session, clear or resume, and the Fabric pane keeps a change made in the last second of a session.
- Useful stuff: new `usage-context` hook that tells Claude how much of the plan's 5-hour and weekly limits is used. It reads a `rate_limits` cache that the statusline now writes.
