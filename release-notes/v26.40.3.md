# v26.40.3

- File and URL openers detach from the pane and report immediate launch failures.
- Text files whose extensions resemble audio or video, including `.ts`, use the default text editor on Linux through `gio launch`. Other targets use `gio open`, with `xdg-open` when gio is unavailable or cannot open the target.
- Windows openers pass paths and URLs literally to ShellExecute, preserving spaces, ampersands and percent escapes. macOS openers preserve literal targets and report failures.
- The onboarding HTML opener detaches all standard streams, tries available browsers and reports when none can open the page.
- Synced the latest pane sources, including the Fabric app pane name, workspace tenant handling and model/catalog refresh fixes.
