# UI Scripts

Scripts that change the Tabular Editor 3 desktop UI rather than the model. Run them in the TE3 C# Script window or save them as macros; they do nothing under `te script`.

## Available Scripts

- `set-ui-font-size.csx` - Set the TE3 UI font and size for the current session (DevExpress default font plus open windows). Edit `fontSize` and `fontName` at the top. Untested across TE3 versions; code editor panes keep their own fonts
